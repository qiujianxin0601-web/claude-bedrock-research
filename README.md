# Claude Bedrock Research

This is a personal software development and quantitative research project using Amazon Bedrock and Anthropic Claude.

## Intended use

- Python and JavaScript coding, debugging, and testing
- Data analysis and research backtesting
- Technical documentation and workflow automation
- Internal experimentation with responsible AI-assisted development

## Safety and scope

- No personally identifiable information is processed or published
- No private trading strategies, credentials, or financial account data are stored here
- Claude is used as a research and development assistant
- The project does not perform automated trading or provide investment advice
